# **Simple-website**

This project is a responsive web development exercise designed to learn and implement technologies like Pug, Sass, and Gulp. As my first web project, it was a hands-on approach to understanding templating with Pug, styling with Sass, and automating tasks with Gulp. I focused on optimizing the development workflow and creating modular, maintainable web pages that adapt seamlessly to different screen sizes.
